# Arrays and Lists Part 1

An adventurer returns from a dungeon with a big haul of loot. He personally evaluates the loot and estimates the value of each item. He then goes to a merchant to get market prices for each item. Given an array of integers of the knights personal estimations of each item *p* and an array of integers of the market prices for each item *m* return the difference between the total of the market prices and the estimations.

## Contraints

- 0 <= *p.length* <= 10^5
- 0 <= *m.length* <= 10^5
- *p.length* = *m.length*
- 0 <= *p[i]* <= 10^5
- 0 <= *m[i]* <= 10^5

## Case 1

Input:

- p = [1,2,4,5]
- m = [2,2,5,10]

Output:

- 7

## Case 2

Input:

- p = [1,2,4,5]
- m = [2,1,5,0]

Output:

- -4
