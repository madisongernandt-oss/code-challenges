# Arrays and Lists Part 0 - Warm Up

Given an array of integers *a* and an integer *k*, Modify the array in-place so that every element is incremented by *k*. Do not return anything.

## Contraints

- 0 <= *a.length* <= 10^5
- 0 <= *k* <= 10^5

## Case 1

Input:

- a = [1, 2, 3, 4, 5]
- k = 1

Output:

- [2, 3, 4, 5, 6]

## Case 2

Input:

- a = [1, 2, 3, 4, 5]
- k = 0

Output:

- [1, 2, 3, 4, 5]
