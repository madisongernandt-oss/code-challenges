# Arrays and Lists Part 2

A guild manager is figuring out where to dispatch an experienced party. He only wants to dispatch this party to a place with more than one report. Given an array of strings with city names *c*, return the city where the party should be dispatched. Each city occurrence counts as one report. There will be only one city with many reports.

## Contraints

- 0 <= *c.length* <= 10^5
- 0 <= *c[i].length* <= 10^5

## Case 1

Input:

- c =   ["Plateau", “Haven”, “Insomnia”, “Grand Trad”, "Plateau" , “Sunville”]

Output:

- "Plateau"

## Case 2

Input:

- c =  ["Plateau", “Haven”, “Insomnia”, “Grand Trad”, “Sunville”, "Bronze City", "Sunville"]

Output:

- "Sunville"
