# Maps Part 0 - Warm Up

Given an array of names *n* (Last, First), store the names in first name, last name in the provided map *m* by an identifier. This can be anything you want, just make sure it is unique. Do not return anything.
You will see "Passed" if you have stored the names correctly.

## Contraints

- 0 <= *n.length* <= 10^5

## Case 1

Input:

- n = ["Doe, John", "Smith, Jane", "Johnson, Jim"]

Output:

If you store the names correctly, you will pass.

## Case 2

Input:

- n = ["Doe, John", "Smith, Jane", "Johnson, Jim", "Williams, Mary", "Brown, Bob"]

If you store the names correctly, you will pass.

Write your answer in the Solution class, and run the main file / class to test.
