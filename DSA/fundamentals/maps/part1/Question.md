# Maps Part 1

A villager goes to a merchant and wants to buy exactly two items while using all of his budget. Given an array of integers *p* and a budget *b*, return any two indices as an array that meet this criteria.

## Contraints

- 0 <= *p.length* <= 10^5
- 0 <= *b* <= 10^5
- 0 <= *p[i]* <= 10^5

## Case 1

Input:

- p = [4,1,4,7,3,6]
- b = 7

Output:

- [0,4]
- Other possibilities are [1,5], [2,4]

## Case 2

Input:

- p = [1,2,3,4,5,6,7]
- b = 10

Output:

- [2, 6]
