# RCBC Coding Challenges

This repository holds coding challenges related to Data Structures & Algorithms, Object-Oriented Programming, and Debugging.
It is mainly used for club sessions, but it can be used for personal practice as a take home assignment.

Problems are gamified to help problem solving be more engaging and also easier to visualize.

## Structure

- /DSA/ directory contains the coding challenges related to Data Structures & Algorithms.
- /OOP/ directory contains the coding challenges related to Object-Oriented Programming.
- /Debug/ directory contains the coding challenges related to Debugging.

Each directory contains a series of parts. Parts are divided into easy, medium, and hard.

Each problem has a Question.md file that explains the story and problem you must solve.

If an Explanation.md file is present, it contains the explanation of possible solutions and their time and space complexities.

### Solving

Within your chosen language, there is:

- A judge file that tests your solution against a set of test cases, it also contains a solution.
- A solution file that you must use to write your solution.
- A main file that contains the main class to run your solution.

When you are ready to test your solution, run the main file to see if your solution is correct.

It is recommended to open the language files in your preferred IDE instead of the entire project.
